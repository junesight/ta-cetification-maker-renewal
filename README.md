# 자보 연장(추가) 진단서 작성기

자동차보험 지급보증 연장을 위한 추가 진단서 자동 생성기입니다.

## 주요 기능
1. **사고 발생일 설정**: 기본값으로 접속일 기준 4주 전(28일 전) 날짜가 자동 설정됩니다.
2. **기본 4주 이후 치료 필요 기간 선택**: 2주, 3주, 4주 선택 가능 (기본값: 4주 선택).
3. **진단서 양식 자동 생성**:
   - 국토교통부 고시 <자동차보험진료수가에 관한 기준> 제12조 제3항 기반 문구 출력
   - 날짜 자동 계산 (사고일 기준 치료 필요 종료일: 2주 선택 시 d+42, 3주 선택 시 d+49, 4주 선택 시 d+56)
4. **원클릭 복사 기능**:
   - 진단서 결과값 복사 (내용 직접 수정 가능)
   - 진단서 '비고' 항목 복사
   - 진단서 '용도' 항목 복사
